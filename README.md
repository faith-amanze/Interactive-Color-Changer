# Interactive Color Changer

A simple webpage that changes the color of a box to a random color each time you click a button.

## Files
- `index.html` – page structure
- `style.css` – styling
- `script.js` – generates a random hex color and applies it to the box on click

## How to run
Download the files, keep them in the same folder, and open `index.html` in a browser.
